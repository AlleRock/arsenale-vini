# L'app legge QUESTO file per intero ad ogni avvio. Non ci sono vini
# nascosti nel codice: se un vino non è qui sotto, non compare in app.
#
# Una riga per vino. Sei campi separati da " | " (spazio, barra, spazio):
#
#   Nome | Cantina | Tipo | Regione | Prezzo | Descrizione
#
# Tipo (esattamente uno di questi, minuscolo): bianco, rosato, rosso, bollicina, dolce
# Regione: una regione italiana, scritta come preferisci (es. Piemonte, Liguria,
#          Toscana, Sicilia...) — comparirà nel filtro esattamente come la scrivi,
#          quindi usa sempre la stessa grafia se riusi una regione già presente.
# Prezzo: testo libero, es. "12€ - 15€"
# Descrizione: testo libero, può contenere qualunque cosa (anche il simbolo | )
#
# Le righe vuote e quelle che iniziano con # vengono ignorate: usale per note.
#
# Per aggiungere un vino: scendi in fondo al file e aggiungi una riga sul
# modello di quelle già presenti. Salva/commit su GitHub, l'app la vedrà
# alla prossima apertura.
